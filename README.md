# 🚀 Flask Mongo Form

A simple Flask web app to submit form data and store it in MongoDB Atlas.

---

## 🛠️ Tech Stack

* Flask (Python)
* MongoDB Atlas
* HTML (Jinja Templates)

---

## ⚡ Quick Start

```bash
pip install flask pymongo python-dotenv
python app.py
```

---

## ⚙️ Environment Setup

Create a `.env` file:

```
MONGO_URI=your_mongodb_connection_string
```

---

## 🌐 Usage

* Open → http://127.0.0.1:5000/
* Submit form → Data saved in MongoDB
* Redirect → Success page

---

## 🔐 Security Note

Sensitive data like `.env` is not included.
Use `.env.example` as reference.

## ✨ Features

* Form submission
* MongoDB integration
